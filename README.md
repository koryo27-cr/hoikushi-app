# 保育士試験 問題集（全9科目）

保育士試験の筆記試験 全9科目の練習用Webアプリです。ブラウザで開くだけで使えます（ログイン不要）。

- 保育原理／教育原理／社会的養護／子ども家庭福祉／社会福祉／保育の心理学／子どもの保健／子どもの食と栄養／保育実習理論
- 全966問（各科目100問以上）。一問一答のほか、本試験と同じ形式（○×の組合せ、事例問題、空欄補充、人物・事項の組合せ、2024年後期からの「正しいものを○つ選びなさい」形式）を収録
- **学習ツールとしてのフィードバック**：間違えた問題は「別の形」（1文ずつの○×判定、組合せを使わない選択、空欄ごとの選択、答えを思い出してからの判定）に作り替えて出題し、元の形式 → 翌日 → 4日後と段階的に復習。間違えたときは「正しい知識の整理」「分野の要点」「関連知識」を表示。分野ごとの要点ページと苦手分野の表示つき
- **頻出問題は形式を変えて繰り返し出題**：公式過去問（直近3回）の出題テーマを分析し、テーマごとの出題数で頻出度を判定。頻出問題は正解しても日をおいて別の形式（1文ずつ○×、同じテーマの他の問題と混ぜて○×、逆向き、語句の正誤判定など）で出題し、「いくつの形式で正解できたか」で理解度を表示。科目画面の頻出テーマから特訓もできる
- **学習プラン（計画エンジン）**：受験日・受験科目（今回／次の回／免除）・1日に使える時間を入れると、残り日数から「基礎→演習→実戦→直前」の段階を割り振り、毎日の「今日のメニュー」を作る。テンプレートは1年（2回受験）・半年・3か月・直前1か月・最後の1週間。区切りの日（基礎を終える日）も設定でき、間に合わないときは「時間を増やす／科目を減らす」を提案。毎日の実績で割り直すので遅れても立て直し不要。最後の7日間は日別メニュー（試験の時間割に合わせ、試験に近い科目ほど後ろ）。受験科目の変更は履歴に残る
- **模擬試験**：科目ごとに本番と同じ問題数・制限時間（教育原理・社会的養護30分、他60分）。途中で答えを見せず、最後に採点と6割判定。分野の比率は公式過去問の出題配分に合わせる
- **合格ライン信号**：直近の正答率・最頻出テーマの理解度・模擬試験の点から、科目ごとに6割に届きそうかを色で表示
- **自信度と間違いの理由**：正解したら「確信あり／迷った」（迷った問題も復習へ）、間違えたら「知らなかった／うろ覚え／読み違い／うっかり」をワンタップで記録。読み違いが多いと「不適切なもの」を選ぶ問題を今日のメニューに追加
- **日ごとの学習ログ・学習カレンダー・継続日数**、1問あたりの時間を記録から補正
- **科目をまたぐつながり**（同じ法律・人物・制度が他科目のどの問題に出るか）、**用語集・年表**（暗記カードつき）、統計問題の表を表として表示、問題ごとの「根拠」（制度情報の鮮度管理）
- **先生とのやりとり（指導者フィードバック）**：生徒は「先生に送る」で学習の要約をまとめたレポートコード（またはリンク）を作り、LINEやメールで先生へ。送る前に先生の画面での見え方を確認できる（ニックネームで使え、本名や1問ごとの細かい記録は送らない）。先生は同じアプリの「指導者ページ」に貼ると、クラス一覧・声かけが必要な生徒（3日以上学習なし／計画から大きく遅れ／正答率の低下／復習がたまっている）・生徒の詳細（科目ごとの合格ライン信号、苦手分野、間違いの理由の内訳、迷って正解した問題、模擬試験の推移）・クラス共通のつまずき・面談用の1枚レポート（印刷）が見られる。コメント（定型コメントつき）・課題（分野の問題／頻出テーマ／模擬試験／要点を読む／復習／自由課題、期限つき）・受験科目と1日の時間の変更を「返信コード」で返すと、生徒のトップにコメント、今日のメニューに課題が入り、終わったかどうかは次のレポートで先生に届く。クラス全員あての返信も作れる。サーバーは使わない
- **アプリから直接提出・返信も自動で届く（Googleスプレッドシート）**：先生のGoogleスプレッドシートに `server/Code.gs`（Apps Script）を置いてウェブアプリとして公開し、指導者ページで「接続する」。先生が作った署名つきの「参加リンク」を生徒が開くと教室に参加し、「提出する」ボタン（または1日1回・学習のあとの自動提出）でレポートが「提出」シートに届く。先生の返信（コメント・課題・受験科目の変更）は「返信」シートに置かれ、生徒がアプリを開くと署名を確かめて自動で取り込む。提出の読み出し・返信の書き込みは指導者ページのパスコードで開いた先生だけ、生徒あての返信は本人の端末の鍵がないと受け取れない。受け取り先がなくてもコードでのやりとりは使える
- **指導者ページはパスコードで保護**：指導教員のパスコードを知る人だけが開ける（複数のパスコードを発行・個別に無効化できる）。先生の返信コードには署名がつき、生徒のアプリは署名を確かめてから取り込むので、パスコードを知らない人が作った返信は受け付けない。パスコードの発行・無効化は `node tools/teacher_keys.mjs`（使い方はファイルの先頭）。リポジトリにはパスコードで暗号化した鍵（`teacher_keys.js`）だけがあり、パスコードそのものは含まれない
- **オフライン対応**（一度開けば電波がなくても使える）、**実技試験の準備チェック**
- 学習記録はブラウザに保存。「記録の引き継ぎ」コードで他の端末へ移せます（学習プラン・ログ・模擬試験の結果も含む）
- iPhoneはSafariで開き、共有 →「ホーム画面に追加」でアプリのように使えます

## ファイル構成
- `index.html` … 画面とスタイル
- `app.js` … アプリ本体
- `subjects/*.js` … 科目ごとの問題データ
- `teacher_keys.js` … 指導者ページの鍵（`tools/teacher_keys.mjs` で生成）
- `glossary.js` … 用語集・年表のデータ（`node tools/check_glossary.js` で問題の解説と年を照合）
- `sw.js`・`manifest.webmanifest` … オフライン対応・ホーム画面に追加

問題と解説は試験対策用に独自に作成したものです。過去問の転載ではありません。
