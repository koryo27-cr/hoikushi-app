# 保育士試験 問題集（全9科目）

保育士試験の筆記試験 全9科目の練習用Webアプリです。ブラウザで開くだけで使えます（ログイン不要）。

- 保育原理／教育原理／社会的養護／子ども家庭福祉／社会福祉／保育の心理学／子どもの保健／子どもの食と栄養／保育実習理論
- 全966問（各科目100問以上）。一問一答のほか、本試験と同じ形式（○×の組合せ、事例問題、空欄補充、人物・事項の組合せ、2024年後期からの「正しいものを○つ選びなさい」形式）を収録
- **学習ツールとしてのフィードバック**：間違えた問題は「別の形」（1文ずつの○×判定、組合せを使わない選択、空欄ごとの選択、答えを思い出してからの判定）に作り替えて出題し、元の形式 → 翌日 → 4日後と段階的に復習。間違えたときは「正しい知識の整理」「分野の要点」「関連知識」を表示。分野ごとの要点ページと苦手分野の表示つき
- **頻出問題は形式を変えて繰り返し出題**：公式過去問（直近3回）の出題テーマを分析し、テーマごとの出題数で頻出度を判定。頻出問題は正解しても日をおいて別の形式（1文ずつ○×、同じテーマの他の問題と混ぜて○×、逆向き、語句の正誤判定など）で出題し、「いくつの形式で正解できたか」で理解度を表示。科目画面の頻出テーマから特訓もできる
- 学習記録はブラウザに保存。「記録の引き継ぎ」コードで他の端末へ移せます
- iPhoneはSafariで開き、共有 →「ホーム画面に追加」でアプリのように使えます

## ファイル構成
- `index.html` … 画面とスタイル
- `app.js` … アプリ本体
- `subjects/*.js` … 科目ごとの問題データ

問題と解説は試験対策用に独自に作成したものです。過去問の転載ではありません。
