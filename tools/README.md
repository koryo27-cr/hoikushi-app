# 問題データの作り方

- `specs/*.py` … 科目ごとの問題の元データ（教育原理以外の8科目）
- `build_all.py` … `specs/` から `../subjects/*.js` を生成する（`python3 tools/build_all.py`）
- `kyouiku-genri-src/` … 教育原理の元データ（`subjects/kyouiku-genri.js` は手作業で変換済み）

## ルール
- 学習記録は問題IDに紐づくため、問題は各リストの**末尾に追加するだけ**にする（途中への挿入・削除・並べ替えをしない）。
- 一問一答は `(分野, 問題, [正解, 誤答, 誤答, 誤答], 解説)`。選択肢はアプリ側でシャッフルされる。
- 本番形式は `tf`（○×組合せ）/ `match`（組合せ）/ `blank`（空欄補充）/ `c5`（5択）。誤りの選択肢は自動生成。
