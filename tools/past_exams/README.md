## 集計の要点（3回分）
- **保育原理**：保育所保育指針が大半。特に「保育の内容（乳児／1歳以上3歳未満／3歳以上のねらい及び内容）」が毎回3〜5問。総則、子育て支援（第4章）も毎回。問20は毎回「統計の読み取り」。事例問題が毎回4問前後。
- **教育原理**：西洋の教育思想（毎回2問）、日本の教育史（毎回1〜2問）、法規（憲法・教育基本法）、幼稚園教育要領、そして近年の教育政策（COCOLOプラン、こども大綱、中教審答申、生成AIガイドライン等）が毎回2〜3問。
- **社会的養護**：施設運営指針・各種ガイドライン（毎回2〜4問）、里親・ファミリーホーム、入所児童等調査などの統計（毎回1問）、問9・問10は毎回事例。
- **子ども家庭福祉**：こども基本法・こども施策（こども未来戦略、こどもまんなか実行計画など）、児童福祉法の事業・センター、専門職（こども家庭ソーシャルワーカー、意見表明等支援員）、手当・支援事業、調査統計。
- **社会福祉**：相談援助（理論・技法・過程）と法律・実施体制がそれぞれ毎回4問前後、権利擁護（成年後見・苦情解決等）、歴史・理念も毎回。
- **保育の心理学**：発達理論、乳幼児の認知・言語、社会情動的発達が中心。青年期〜高齢期（問11・12）、家族・子育て家庭（問13・14）、心の健康・虐待（問15・16）は毎回同じ位置で出題。
- **子どもの保健**：事故防止・安全・救急、感染症、慢性疾患・アレルギー、保健計画・健康診断・与薬がそれぞれ毎回3〜5問。発育・母子保健統計も毎回。
- **子どもの食と栄養**：栄養素と食事摂取基準、各種調査・指針（乳幼児栄養調査・食生活指針）、食育（食育基本法・保育所の食育指針）が中心。
- **保育実習理論**：問1〜6は毎回音楽（和音・楽語・移調・リズム・音楽の知識）、問7は指針「表現」、問8描画の発達、問9色彩、問10〜12造形技法・材料、問19・20は毎回施設実習の事例。
